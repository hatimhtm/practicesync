How it works: you give it patient names. For each one, Hope Assistant looks the patient up in Practice Fusion, reads every visit's date and doctor, finds which main doctor they fall under, then books the appointment in SimplePractice with that doctor's codes — and saves it. You watch the whole thing happen in Chrome: the cursor moves, types, and clicks, step by step.

Doctors & Codes

Each main doctor supervises several other doctors. When a patient is seen by one of those doctors, the visit is filed under their main doctor — using that doctor's codes.

Main doctors

Each main doctor has a 2-letter code (you choose it) that Hope Assistant adds to every appointment so the visit is filed under the right main doctor — e.g. Caryn = GP, Heather = GO, Karine = GN.

Welcome — let's set up Hope Assistant

It reads each visit from Practice Fusion and books it in SimplePractice for you — and you'll watch it work: the cursor moves, types, and clicks right on the screen.

A few quick steps — about five minutes. Hope Assistant opens its own Chrome window, so you can leave your everyday Chrome open.

Permissions — kept simple

Here's exactly what Hope Assistant needs on your Mac. No surprises:

✅
No special permission required. Driving Chrome needs no Accessibility, Screen Recording, or anything scary.
🔔
It may ask permission to send a notification when a sync finishes. Allow it for a heads-up, or skip it — your choice.
🔒
Patient data never leaves this Mac, and you sign in inside Hope Assistant's own Chrome window — the app never sees a password.
If macOS ever shows a box about “App Management,” just click Don't Allow — Hope Assistant doesn't need it and works fine without it.

Step 1 — Your doctors

Load the doctor list, then open it to review and save.

Step 2 — Practice Fusion

Press the button — a Chrome window opens. If it doesn't land on Practice Fusion, type your address into Chrome and press Enter (the helper follows you). A bar guides you: click the field, then press “Next step.” You can re-click to fix it, or press Back. The fields, in order:

  1. The search box — then type any patient's name
  2. The patient in the results
  3. The patient name at the top of their chart
  4. One visit row, then the doctor and the date in it

After this you only type a name — no more addresses.

Step 3 — SimplePractice

Press the button — a Chrome window opens. If it doesn't land on SimplePractice, type its address into Chrome and press Enter (the helper follows you). For each field the bar names: click it, then press “Next step.”

For the Save button you just click it and press Next — that only teaches the app where Save is. Nothing is booked during setup.

Step 4 — Watch a test run

Type a patient's name, then pull their visits. Watch the Chrome window — you'll see the cursor search and read. Nothing is booked; this only reads. When the doctor and date look right, press Finish.
